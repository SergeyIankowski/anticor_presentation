# Позит — antikor.pozit.by

Статус: реализован и проверен сбор живого одностраничного сайта https://antikor.pozit.by/.
Дата проверки: 2026-10-26. Варианты HTTP и www также ответили HTTP 200; рабочий адрес — HTTPS без www.

## Сбор

```sh
cd instances/antikor.pozit.by
npm run parse
# Изолированный предпросмотр:
npm run parse -- --output-dir /tmp/antikor.pozit.by-preview
node --test test/extract.test.js
```

Из корня репозитория:

```sh
pnpm exec biome check instances/antikor.pozit.by/src instances/antikor.pozit.by/test/extract.test.js
cmp instances/antikor.pozit.by/src/parse.js template/src/parse.js
```

Playwright и сетевые команды требуют разрешённого запуска вне sandbox. Установка зависимостей не требуется.
`src/parse.js` сохранён без изменений относительно шаблона. Используются только экспортированные `runSite`, `extractPage`, нормализация, валидация и enrichment hook из общего пакета.

## Покрытие и доказательства

Вся информация размещена на `/`; ссылки меню ведут на секции этой же страницы. Юридические страницы, изображения и внешние карты не считаются отдельными страницами услуг.

- 1 страница, 2 пакета антикоррозийной обработки, 4 цены: каждый пакет представлен с материалами Noxudol и Mercasol. Переключателей автомобилей, калькулятора и скрытых состояний прайса на странице нет.
- `.price-card` / `.pricing-title` / `.price-list li` — названия и состав пакетов; `.material-price-row` связывает каждую исходную цену с материалом. Числа извлекаются заново из `.material-price`, в исходниках парсера цен нет. Проверочная HTML-фикстура содержит фрагменты реально прочитанного сайта.
- Источник каждой услуги — фактически собранная страница `/`, без фрагмента. Регистр `name_original` соответствует отображаемому тексту, включая CSS text-transform, чтобы название присутствовало в `pages[].text`.
- `#materials`: 7 материалов с зонами применения и перечисленными свойствами; `#preparation`, `#benefits`, `#guarantee` — технология, подготовка и заявления компании; `#faq` — 5 вопросов с ответами.
- `.footer__company`, `.map-address-value`, контакты и JSON-LD — компания, телефон, мастерская, юридический адрес, УНП, часы работы и способы связи. Адрес мастерской отделён от юридического адреса; часы JSON-LD оставлены в исходной структуре.
- `snapshots/<run-id>/001.json` и `antikor.pozit.by.json` сохраняют текст, заголовки, метаданные, JSON-LD, ссылки, изображения и дополнительный блок `pozit` с извлечёнными карточками и разделами. Источники и время загрузки сохранены.

## Ограничения и оговорки источника

- Все опубликованные цены имеют квалификатор «от». В сравнении это `price_min`, а не точная `price`. Финальная цена фиксируется после осмотра. Цена по запросу или отсутствующая цена даёт `prices: []`; запасных значений из старых JSON нет.
- Сайт не задаёт классы автомобилей. Технический идентификатор `unspecified` использует исходное слово «автомобиля» из заголовка страницы и класс `other`; он не означает единую цену для любого автомобиля. Отдельная единица тарификации на сайте не написана: `pricing_evidence[].unit` равна `null`; состав пакета указан в описании.
- Средний срок указан как «30 часов», точный срок — после осмотра. Сохранены исходный текст и единица `hours`, без выдуманных границ min/max.
- JSON-LD `priceRange` и meta description содержат «от 850», что расходится с видимым прайсом. Эти метаданные сохранены как доказательства и не используются для цен услуг. Предупреждение включено в отчёты.
- На странице одновременно встречаются разные рейтинги/числа отзывов. Они сохранены в исходном тексте и JSON-LD, не объединены в проверенный рейтинг.
- Гарантия до 3 лет, свойства материалов, безопасность, опыт и видеоотчёт — заявления сайта, не независимые подтверждения. В FAQ выходные указаны по предварительной записи; часы будней находятся в JSON-LD.

## Проверки

Четыре теста проверяют DOM-извлечение, обе схемы, все варианты материалов, изменение текущих цен, диапазоны и квалификаторы, отсутствие подстановки JSON-LD, пустые цены по запросу и отказ при пропаже карточек/исходного названия. Предпросмотр и финальный live-run используют общий runner без ослабления валидации.
